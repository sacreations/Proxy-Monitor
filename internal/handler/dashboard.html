🛠️ API Documentation

GET /health Service Health Check

Returns the current status of the service and Redis connection. Used for load balancer health checks.

GET /config Get Monitor Configuration

Retrieves current background polling settings, including interval and request timeouts.

POST /config Update Configuration

Updates polling parameters. Restarts the background poller immediately to apply new settings.

{ "check_interval_seconds": 30, "request_timeout_ms": 5000 }
GET /proxies List All Proxies

Returns the complete list of monitored proxies with aggregate metrics (total checks, uptime, current status).

POST /proxies Ingest Proxies

Adds new proxy URLs to the monitoring pool. Use "replace": true to clear the existing pool before adding.

{ "urls": ["http://..."], "replace": false }
GET /proxies/{id}/history Proxy Probe History

Returns a time-series array of the last 100 probe results for a specific proxy ID.

DELETE /proxies Clear Proxy Pool

Removes all proxies from monitoring. Note: Alert history is preserved for audit purposes.

GET /alerts Alert History

Lists all global failure rate alerts. Includes both active and resolved alerts with failed proxy IDs.

GET /metrics Operational Metrics

Provides real-time statistics including total checks, failure rate, and alert counts for Prometheus or dashboarding.
